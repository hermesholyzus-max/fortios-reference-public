# FortiOS 7.4.13 Topic Index

This public mirror contains sanitized text references extracted from the official FortiOS 7.4.13 Administration Guide. Read only the topic needed for the current task.

## Topic map

- `getting-started.txt`  initial setup and GUI/CLI basics
- `network.txt`  interfaces, VLAN, DHCP, routing, diagnostics
- `policy-and-objects.txt`  firewall policy, NAT, addresses, services
- `security-profiles.txt`  AV, IPS, web/DNS filtering, SSL inspection
- `ipsec-vpn.txt`  IPsec phase 1/2, site-to-site VPN, troubleshooting
- `ssl-vpn.txt`  remote access, portals, authentication
- `system.txt`  administrators, SSH, backups, HA, system settings
- `troubleshooting.txt`  flow debug, packet capture, routes, and logs

## Safety

This is a model-neutral reference. Live device configuration takes precedence over examples. Before any change, verify the FortiGate model, FortiOS build, VDOM, interface layout, topology, certificates, secrets, and live objects. Do not copy a complete configuration between different models.

The public mirror intentionally omits source PDFs, scripts, device exports, and user-specific infrastructure data. Example addresses, usernames, emails, tokens, and key material from the source guide have been anonymized or redacted.
